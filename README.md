# AeroLithix Player (ALPlayer)

A sleek, lightweight, and high-performance media player designed for smooth audio and video playback, full custom skinning, and deep audio customization.

---

## ✨ Key Features

- 🎥 **Universal Media Engine:** Smooth playback for virtually all audio and video formats (`.mp4`, `.mkv`, `.mp3`, `.flac`, `.avi`, `.wav`, `.ogg`, and more) with full hardware acceleration.
- 🎨 **Dynamic Skinning System:** Fully customizable dark Aero visual style with real-time peak visualizers, custom color themes, and multi-language support.
- 🎛️ **10-Band Equalizer & DSP Effects:** Built-in graphic EQ with customizable presets, dynamic bass boost, and precision speed/pitch controls.
- 💬 **SRT Subtitle OSD Engine:** Automatic subtitle detection and parsing with clean, transparent screen overlays.
- 🛠️ **AeroLithix Setup & Repair Wizard:** Custom standalone installation, clean Windows Settings (`Apps & Features`) integration, automatic file associations, and built-in repair/uninstall tools.

---

## 🚀 Installation

1. Head over to the **[Releases](../../releases)** section.
2. Download `alp_installer.exe`.
3. Run the installer to set up **AeroLithix Player** on your system.

## 🎹 Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Space` | Play / Pause |
| `S` | Stop Media |
| `F11` | Toggle Fullscreen |
| `Esc` | Exit Fullscreen |
| `Left` / `Right` | Seek Backward / Forward (5s) |
| `Up` / `Down` | Volume Up / Down (5%) |
| `M` | Mute / Unmute Audio |
| `Ctrl + O` | Open File |
| `Ctrl + U` | Open Network Stream / URL |
| `Ctrl + T` | Toggle Always-on-Top Mode |

- **Audio:** `.mp3`, `.wav`, `.flac`, `.aac`, `.ogg`, `.opus`, `.m4a`, `.alac`, `.wma`, `.ac3`, `.dts`
